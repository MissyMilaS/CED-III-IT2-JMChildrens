# Datos

El proyecto utiliza GoEmotions como fuente de datos. Coloca la copia original
del dataset en `data/raw/` y conserva esos archivos sin modificaciones.

El preprocesamiento (limpieza de texto, preparación de etiquetas y
tokenización) debe documentarse y guardar sus resultados en `data/processed/`.
No se incluye ni se descarga automáticamente el dataset en este repositorio.
