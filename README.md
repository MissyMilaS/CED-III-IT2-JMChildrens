# JMChildrens

## Unidad 3: Máquinas de Turing y aplicaciones

Espacio de trabajo para el análisis y la clasificación de emociones en textos
usando el dataset GoEmotions. El proyecto contempla análisis exploratorio,
un clasificador de referencia, modelos neuronales y una extensión opcional con
Transformers.

## Requisitos e instrucciones

Se recomienda Python 3.10 o posterior. Instala las dependencias del proyecto
con:

```bash
python -m pip install -r requirements.txt
```

Abre y ejecuta los notebooks en orden desde `notebooks/`, comenzando por
`01_eda.ipynb`. El dataset original debe colocarse en `data/raw/`; los datos
preprocesados y los resultados se guardan en las carpetas correspondientes.

Las dependencias, rutas de datos y comandos de ejecución específicos se
documentarán al implementarse el flujo de trabajo.
